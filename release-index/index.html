LacyLights Raspberry Pi

Turn a Raspberry Pi into a stage lighting controller

Install

Run this single command in a terminal on your Raspberry Pi (64-bit Raspberry Pi OS). It downloads the latest stable release, verifies its checksum and sets up the system.

(set -o pipefail; curl -fsSL https://dist.lacylights.com/releases/rpi/install.sh | bash) && cd ~/lacylights-setup && sudo bash scripts/setup-local-pi.sh

When setup finishes, open http://lacylights.local from any device on the same network. See the README for remote installs, WiFi setup and troubleshooting.
